# George Washington RTS

Browser-based prototype for an educational American Revolutionary War real-time strategy game.

## Phase 1 foundation

- Strategic campaign map
- American and British city ownership
- Independent city garrison counts
- Visible army position
- City inspection panel
- Army movement to cities
- Preparation for future tactical battle handoff

Open `index.html` in a browser or enable GitHub Pages for the `phase-1-foundation` branch.

## Development

This prototype uses plain HTML, CSS, and JavaScript with no build step or external dependencies.

1. Select Washington's army.
2. Select a city.
3. Use **Move selected army here**.

Cities with no defenders are captured. Cities with defenders display the defender count, but the tactical battle system is intentionally not implemented yet.
